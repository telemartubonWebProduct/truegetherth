# R2 — โปรแนะนำแบบแท็บ และหน้าแรกหลังหนัง

วันที่ 1 ตุลาคม 2026 · ส่วนที่สองของงานออกแบบใหม่ (R1–R4) ต่อจาก [R1-HOME-FILM.md](R1-HOME-FILM.md): ต่อจากหนังในหน้าแรกเป็นโปรแนะนำแบบแท็บหมวด การ์ดมีรูปเลื่อนได้ แล้วปรับส่วนอื่นของหน้าแรกให้เข้ากับ R1 ใช้แพ็กเกจจาก catalog ที่มีอยู่ ไม่แต่งโปรหรือราคาใหม่

## สิ่งที่ได้

- **โปรแนะนำ** (`src/components/site/home/PromoShowcase.tsx` + `PromoTabs.tsx`) แทนส่วน "แพ็กเกจเด่น" เดิม อยู่ถัดจากหนังทันที
  - แท็บ 4 หมวด: เน็ตบ้าน (6 การ์ด), มือถือรายเดือน (6), เติมเงิน (5), โซลาร์เซลล์ (3)
  - แต่ละแท็บเป็นแถวการ์ดที่เลื่อนข้างได้ (scroll-snap) การ์ดถัดไปโผล่ขอบขวาเสมอ บนจอตั้งแต่แท็บเล็ตมีปุ่มเลื่อนซ้าย/ขวาที่ปิดเองเมื่อสุดแถว มือถือปัดด้วยนิ้ว
  - การ์ด: รูปด้านบน (ความเร็วเน็ตบ้านตัวใหญ่ทับภาพ), ชื่อ, สิ่งที่ได้ (มือถือ), ราคาตัวใหญ่ + VAT, สัญญา/ระยะเวลา, ไอคอนสิทธิประโยชน์ 4 อันแรกและ "+N", ปุ่ม "สนใจแพ็กเกจนี้" (LINE ฝ่ายขายเหมือนเดิม) และลิงก์ "ดูรายละเอียด" ไปหน้าของแพ็กเกจ (`/packages/<รหัส>` จาก R3)
  - ใต้การ์ดมีหมายเหตุของแท็บ (เช่น "บริการของ W&W Energy แยกจากแพ็กเกจของทรู") และปุ่มดูทั้งหมดของหมวด
  - พื้นกรมท่า (`tone: ink`) ต่อจากฉากกลางคืนของหนัง มีแสงม่วง (glow) ใต้การ์ด การ์ดคงพื้นขาวตามธีม
- **เลือกบริการ** เป็นการ์ดรูปภาพ 4 ใบ ข้อความขาวบนเงาไล่สี โซลาร์ยังมีป้าย "บริการของ W&W Energy"
- **หัวข้อทุกส่วนของหน้าแรก** ใช้ขนาดเดียวกัน (Anuphan, `tm-section-title`) ให้จังหวะเดียวกับหนัง
- ลำดับหน้า: หนัง → โปรแนะนำ → เลือกบริการ → อุปกรณ์ Wi-Fi → แพ็กเสริมมือถือ → ขั้นตอน → โซลาร์ → FAQ

## ราคาและข้อมูล

- การ์ดอ้างแพ็กเกจด้วยรหัสเท่านั้น ราคา ความเร็ว สัญญา และสิทธิประโยชน์มาจาก catalog ตรงๆ (ยังเป็นราคาที่ยังไม่ยืนยันตาม [ไฟล์ตรวจราคา](price-review-2026-10-01.xlsx)) การ์ดเพิ่มแค่รูป
- คำอธิบายส่วนโปรบอกให้ทักเจ้าหน้าที่เพื่อยืนยันราคาและเงื่อนไขล่าสุดก่อนสมัคร เพราะราคายังไม่ผ่านการยืนยัน
- การเลือกแพ็กเกจลงแท็บเป็นตัวเลือกเริ่มต้นของทีมพัฒนา (แพ็กเกจเด่นเดิม 3 รายการขึ้นก่อน) เจ้าของเปลี่ยนได้ใน editor
- แพ็กเกจที่ซ่อน (`hidden`) เลือกลงการ์ดไม่ได้ และซ่อนแพ็กเกจที่การ์ดยังใช้อยู่ไม่ได้ (ตรวจทั้งตอน build และตอนบันทึกร่าง)

## รูป

ยังไม่มีภาพ S1–S8 จาก Google Flow จึงใช้ภาพเดิมของเว็บเก่าใน `public/assets` ที่ไม่มีตัวอักษร ราคา หรือโลโก้ เพิ่มในคลังสื่อ 15 รูป (`scene-*`, `people-*`) ชนิด `generated` เพราะลักษณะเป็นภาพสร้างด้วย AI และไม่มีบันทึกที่มา — **เจ้าของต้องยืนยันสิทธิ์ใช้งาน** โซลาร์ใช้ภาพถ่ายจริงของ W&W Energy ที่มีอยู่แล้ว ภาพเก่าที่มีราคาหรือข้อความโปรติดอยู่ในรูป (แบนเนอร์เน็ตบ้าน, กล้อง CCTV, TrueID TV, สินค้าโซลาร์) ไม่ใช้ เพราะอาจขัดกับราคาใน catalog

เปลี่ยนรูปของการ์ดหรือการ์ดบริการได้ใน editor เมื่อได้ S1–S8 ให้เพิ่มเข้าคลังสื่อแล้วเลือกแทน

## แก้ใน Mirror editor (schema รุ่น 3)

- `pages.home.promos`: หัวเรื่อง คำอธิบาย สีพื้น และ `tabs` 1–4 แท็บ แต่ละแท็บมี `title`, `items` 1–8 การ์ด (`packageId` เลือกจากรายการแพ็กเกจ, `image` เลือกจากคลังสื่อ), `remark` (เลือกใส่), `packageCta`, `viewAll`
- `pages.home.services.items[].image`: รูปของการ์ดบริการ
- `site.ui.packageDetails`, `scrollPrevious`, `scrollNext`: ข้อความลิงก์และปุ่มเลื่อน (สองปุ่มหลังสำหรับโปรแกรมอ่านหน้าจอ)
- ในโหมดแก้ไข ทุกแท็บแสดงพร้อมกันเรียงลงมา (มีชื่อแท็บเป็นหัวข้อ) จึงคลิกการ์ดไหนก็ได้ คลิกการ์ดแล้วแผงแสดงตัวเลือกแพ็กเกจ (ใหม่: ตัวเลือกแพ็กเกจเดียว `package` แทน `packageList` ที่ไม่มีใครใช้แล้ว) และรูป
- จำนวนแท็บ/การ์ดยังคงที่ตามข้อตกลง M3 จนกว่า R4 จะเปิดเพิ่ม/ลบ/เรียงรายการ
- `CONTENT_SCHEMA_VERSION` เป็น 3 ร่างที่บันทึกด้วยรุ่น 2 (ถ้ามี) จะแสดงเป็นปัญหาให้ทิ้ง

## การเข้าถึงและการโหลด

- แท็บตามแบบ WAI-ARIA tabs: ลูกศรซ้าย/ขวา, Home, End ย้ายแท็บ มีเฉพาะแท็บที่เปิดอยู่ในลำดับ Tab แถวการ์ดโฟกัสได้และเลื่อนด้วยคีย์บอร์ด
- Server render แท็บแรกเปิดไว้ ไม่มี layout กระโดดตอน hydrate ไม่มี JavaScript (`@media (scripting: none)`) แสดงทุกแท็บเรียงกันใต้ชื่อแท็บ
- รูปในแท็บที่ปิดและการ์ดที่เลื่อนพ้นจอเป็น lazy load โหลดเมื่อเปิดแท็บหรือเลื่อนถึง
- เปลี่ยนแท็บมี fade สั้นๆ ตามการกด ปุ่มเลื่อนเลื่อนแบบนุ่ม ทั้งสองอย่างปิดเมื่อเลือกลดการเคลื่อนไหว

## ทดสอบ

- E2E ใหม่ `tests/e2e/home-promos.spec.ts` (desktop + มือถือ): เปิดที่เน็ตบ้านและแต่ละแท็บแสดงการ์ดของตัวเองตาม content, คีย์บอร์ดย้ายแท็บ, ชื่อ/ราคา/สัญญาบนการ์ดตรง catalog และลิงก์ดูรายละเอียดไปหน้าของแพ็กเกจ, ปุ่มเลื่อนทำงานและปิดเมื่อสุดแถว (desktop), ไม่มี JavaScript แสดงทุกแท็บ, หน้าอังกฤษ
- `admin-editor.spec.ts`: editor แสดงทุกแท็บพร้อมกัน เปลี่ยนแพ็กเกจของการ์ดแล้วตัวอย่างเปลี่ยนและบันทึกร่าง; เทสต์เทียบภาพ editor/public รอเฉพาะรูปที่อยู่ในจอ (รูป lazy ในแท็บที่ปิดหรือพ้นจอด้านข้างไม่โหลดทั้งสองฝั่ง)
- Unit: ตรวจ reference ของการ์ด (แพ็กเกจที่ไม่มี/ถูกซ่อน, รูปที่ไม่มี), ป้ายภาษาไทยของทุกช่องใหม่, ชนิดช่อง `package`
- `home-film.spec.ts`: ปุ่มข้ามหนังพาไปหัวข้อโปรแนะนำ

## ข้อจำกัดและงานต่อ

- รูปการ์ดเป็นภาพชั่วคราวจากเว็บเดิม (ลักษณะ AI) รอ S1–S8 จาก Google Flow และการยืนยันสิทธิ์ของเจ้าของ ภาพ 528×297 บางรูปจะดูนุ่มบนจอความละเอียดสูง
- ส่วนแพ็กเสริมมือถือ (ลิงก์หมวด) ยังอยู่ ทับซ้อนกับแท็บมือถือบางส่วน เจ้าของเลือกได้ว่าจะคงไว้หรือไม่ (ลบ section ต้องแก้ layout ใน code)
